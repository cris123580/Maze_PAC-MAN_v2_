# math maze pac-man
Ik  ga een rekenspel maken dat lijkt op Pac-Man en dat in een website wordt gespeeld. Wanneer de website wordt geopend, ziet de speler eerst een startscherm met een knop om het spel te beginnen. De speler kan Pac-Man bewegen met de pijltjestoetsen. Als ik genoeg tijd heb, voeg ik ook de toetsen W, A, S en D toe zodat spelers het spel kunnen besturen zoals in veel andere games.
Tijdens het spel kan de speler punten verdienen. Ik ga proberen om de scores op te slaan als een high score. Als dat lukt wil ik een database gebruiken zodat de scores bewaard blijven.
Daarnaast maak ik een Game Over scherm wanneer de speler verliest. Als de speler een level haalt, verschijnt er een bericht zoals “Gefeliciteerd, je gaat naar het volgende level!”. Ik wil ook meerdere levels maken zodat het spel steeds moeilijker wordt.
Het doel is om een leuke en leerzame game voor kinderen te maken waarin ze rekenen terwijl ze spelen.
